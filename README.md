# Реплика

Android-приложение для локальной расшифровки разговоров, версия 0.6. Android 8+; ARM64 и x86_64.

Материалы оформлены по [шаблону Nuclear IT Hack](https://github.com/grigorevmp/hacathon_template). Стандартный Android-модуль остаётся в `app/`; входная точка раздела исходников — [src/mobile](src/mobile/README.md). [Архитектура](docs/ARCHITECTURE.md), [контракт данных](docs/PROTOCOL.md), [ограничения](docs/LIMITATIONS.md), [результаты тестов](docs/TEST_RESULTS.md).

## Что реализовано

- Запись с микрофона в M4A/AAC, в том числе при заблокированном экране, с уведомлением и кнопкой остановки. После сохранения запись доступна для расшифровки.
- Импорт аудио через системный выбор файла; декодирование Android MediaExtractor/MediaCodec, сведение каналов и PCM 16 кГц во временный файл.
- Локальные Pyannote segmentation + CAMPPlus embeddings: поиск речи и автоматическая кластеризация участников в пределах записи.
- Русский small Zipformer: распознавание речевых окон с временными метками токенов, сборка слов и реплик.
- Быстрая русская пунктуация и регистр через RUPunct_small INT8 (~29 МБ). Дополнительный режим Qwen2.5 0.5B Q4_K_M через JNI llama.cpp. Изменение слов, чисел или их порядка отклоняется.
- Все модели, включая локальную LLM, встроены в APK. Первый запуск автоматически подготавливает и проверяет их; отдельные загрузки и импорт не нужны. Есть прогресс, отмена, просмотр, переключение исходного/обработанного текста и экспорт исходного JSON.
- Промежуточный текст появляется во время ASR; участники и пунктуация уточняются следующими этапами. Показаны прошедшее время, время текущего этапа и участка, прогресс и приблизительный остаток текущего этапа.
- Foreground service продолжает обработку при свёрнутом приложении. Завершённые окна, интервалы участников, голосовые прототипы и обработанные фрагменты сохраняются в `files/processing/<session-id>`; после паузы или перезапуска можно продолжить задание.
- История хранит обе версии текста; результаты также сохраняются в `files/processing/<session-id>/result.json` и `files/last-result.json`.
- Дополнительные режимы: GTCRN для фонового шума, Silero VAD для пауз, 1–8 CPU-потоков и экспериментальный NNAPI. Очищенные окна сохраняют исходную длительность; VAD не сжимает временную шкалу.
- Редактор текста, участника и времён; повторное распознавание только выбранного участка. Whisper tiny multilingual уточняет смешанную речь в режиме транскрибации, без перевода. Экспериментальный Conv-TasNet разделяет два голоса на участке до 6 секунд с проверкой гипотез пользователем.
- Поиск по тексту и ID участника, переход к аудио, отдельные исходный и проверенный экспорты. Иноязычную речь можно уточнить на выбранном участке многоязычной моделью Whisper без перевода. Автоматические словарные подстановки удалены.

Ни распознавание, ни LLM не используют сервер. В APK нет разрешения INTERNET. Большие модели и сторонние библиотеки не коммитятся в Git.

Полный список изменений и ручной чек-лист: [релиз 0.6](docs/RELEASE_0_6.md). Объединены обработка аудио, история/плеер и адаптивная иконка. История сохраняет исходную, пунктуированную и исправленную версии; плеер готовит запись асинхронно, показывает время и перемотку ±10 с. Удаление из истории требует подтверждения и сохраняет внешний аудиофайл.

## Подготовка и сборка (Windows, PowerShell 7)

Установить JDK 17+, Android SDK 35, NDK 27.1.12297006, CMake 3.22.1, Git и curl. Путь Android SDK указать в исключённом из Git `local.properties`.

```powershell
./scripts/setup-engine.ps1
./gradlew.bat :app:assembleDebug :app:testDebugUnitTest :app:lintDebug
```

Скрипт разработчика скачивает зафиксированные зависимости и модели на компьютер с проверкой SHA-256. Gradle автоматически включает необходимые файлы из `.models` в APK; при отсутствии файлов сборка завершается ошибкой. Для пунктуации используется тот же ONNX Runtime, что поставляется в sherpa AAR; отдельный runtime не добавляется. Модели не коммитятся в Git. Результат Gradle: `app/build/outputs/apk/debug/app-debug.apk`.

**Пользователю нужен только APK:** `artifacts/replika-0.6-bundled-debug.apk`. Установить, открыть приложение, дождаться автоматической подготовки и выбрать аудио или видео. Быстрая пунктуация включена по умолчанию, генеративная LLM выбирается отдельно. Для проверки обязательного пункта «локальная LLM» включите соответствующий режим: RUPunct — специализированный классификатор, не замена Qwen при демонстрации этого требования. ZIP, регистрация, интернет и компьютер при обработке не нужны.

После получения результата нажмите «Править / распознать фрагмент». Можно изменить текст, ID и времена вручную либо выбрать диапазон для нового ASR: Whisper — до 29 с, быстрый ASR — до 30 с, разделение двух голосов — до 6 с. Результаты разделения получают временные ID `speaker_review_1/2`; назначьте правильных участников и прослушайте оба текста перед сохранением. «Экспорт исходного JSON» сохраняет автоматическую версию, «Экспорт версии на экране» — текущую пунктуацию и правки.

Нативным библиотекам нужны обычные файлы, поэтому при первом запуске модели копируются из APK в приватную папку приложения и проверяются. Подготовка выполняется вне UI-потока; после прерывания её можно повторить. При следующих запусках подходящие модели повторно не копируются. Повреждённые файлы восстанавливаются из APK. При обновлении комплекта используется временная папка и замена после проверки.

На устройстве APK и подготовленные модели версии 0.6 вместе занимают примерно 1,5 ГБ плюс системные накладные расходы и записи. Обновление использует временную копию моделей; желательно не менее 4 ГБ свободного места.

## Проверка

Актуальная проверка Samsung: [CPU 2/4/6 и NNAPI, иноязычная речь](docs/PHONE_VALIDATION.md), [реальное интервью 81:58 и продолжение](docs/LONG_RECORDING_VALIDATION.md), [говорящие против человеческой разметки](docs/ANNOTATED_SPEAKER_VALIDATION.md). Полный быстрый прогон интервью занял 22:51; это замер VoiceMatcher v1. Новые исправления v3 проверены отдельно на коротких фрагментах. Точность личного интервью без ручного эталона не заявляется. [Сценарий защиты](docs/DEFENSE.md) содержит фактические измерения и ограничения.

Неуверенные локальные голоса больше не склеиваются в одну метку: показаны «Проверить голос N». В редакторе можно разделить пропущенную смену говорящего по времени и позиции курсора. Исправления сохраняются отдельной версией. Автоматический словарь отдельных английских названий удалён.

Для установки и запуска уже собранного APK на работающем эмуляторе из PowerShell в папке проекта:

```powershell
./scripts/install-apk.ps1
```

Скрипт выбирает единственный работающий эмулятор. Для выбора другого устройства передайте `-Serial` с ID из `adb devices`.

Готовый комплект сдачи: `artifacts/replika-0.6-submission.zip` — исходники, APK, документация, видео и измерения с SHA-256. Повторная упаковка после сборки: `python scripts/package-submission.py`. Настройки `config/processing.example.json` описывают параметры конвейера; пользователь выбирает их в приложении.

Перед обработкой можно указать число участников: авто, один голос или верхнюю границу 2–8. У готовой записи доступен пересчёт участников без повторного ASR. В редакторе можно объединить все реплики ошибочно раздробленного участника, изменив ID и включив применение ко всем его репликам. Автоматическая и исправленная версии экспортируются отдельно. Подробности: [стабильность голосов](docs/SPEAKER_CONTINUITY.md).

```powershell
# Подключённый эмулятор/телефон; идентификатор из adb devices
./scripts/test-device.ps1 -Serial emulator-5554
```

Для инструментальных проверок нужны ffmpeg и Python 3 в PATH (подготовка stereo MP3 и шумовой записи); путь Python можно передать через `-Python`. Тестовый русский WAV берётся из официального архива ASR. Отдельный английский диалог с двумя участниками проверяет диаризацию; он не используется для оценки русского ASR. Скрипт устанавливает debug APK и тестовый APK, подготавливает модели исключительно из APK и запускает реальный инференс на Android и выгружает `artifacts/smoke-result.json`. Через `run-as` копируются только тестовые аудиофайлы; для обычного пользователя это не требуется.

Подробности реализации, ограничения и источники: [docs/AUDIO_ENGINE.md](docs/AUDIO_ENGINE.md). Результаты проверок: [docs/VALIDATION.md](docs/VALIDATION.md).

## Ограничения первой версии

Предел в 30 минут снят; импорт файлов пока ограничен 1 ГБ. Диаризация выполняется блоками по 2 минуты с секундным контекстом, ASR — окнами по 6 секунд с контекстом. Модели загружаются последовательно по одному разу за проход. Отмена проверяется между нативными вызовами; диаризация может завершать текущий вызов до освобождения ресурсов. После убийства процесса продолжение запускается пользователем, а не автоматически. Android ограничивает длительность фоновой службы; при системном завершении остаются сохранённые части.

Исходный импортированный файл сохраняется для продолжения и переключения модели пунктуации без повторного ASR. PCM удаляется после успешного результата; во время незавершённого задания PCM16 занимает примерно 115 МБ на час аудио. Источники и контрольные точки пока не удаляются автоматически.

Временные границы приблизительные, получены из ASR-токенов и диаризации, а не из forced alignment. В основном конвейере одновременная речь помечается как неоднозначная (`speaker_unknown`); разделение двух потоков доступно отдельно на выбранном участке до 6 с. Хорошее качество на произвольных русских встречах ещё нужно измерить на размеченном корпусе и физических телефонах.
