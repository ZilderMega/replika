# Реплика

Первоначальный Android-шаблон офлайн-стенографиста. Kotlin, Jetpack Compose, Android 8+.

## Что работает
- Экран приложения на русском языке.
- Выбор аудиофайла через системный Storage Access Framework, сохранение разрешения чтения.
- Открытие записи во внешнем проигрывателе.
- Модель данных и JSON-сериализация по контракту организаторов.
- Интерфейс TranscriptionEngine для локального движка.

## Что ещё не реализовано
ASR, диаризация, локальная LLM, вычисление временных меток, хранение сессий, экран готовой расшифровки и пользовательский экспорт. Шаблон не выдаёт демонстрационный текст за результат распознавания.

## Сборка
Открыть эту папку в Android Studio, выбрать JDK 17 или новее, установить Android SDK 35 и выполнить `gradlew.bat :app:assembleDebug`. Путь SDK задаётся в локальном, исключённом из Git файле local.properties.

## Приватность
Разрешения INTERNET нет. Резервное копирование приложения отключено. Модели должны поставляться локально. Выбор файла использует системный провайдер: для проверки офлайн выбирайте файл из памяти телефона.

## Следующие этапы
Декодирование аудио → VAD → ASR и диаризация → согласование слов и спикеров → локальная LLM с сохранением исходных слов → просмотр и JSON-экспорт. Модели выбираются по измерениям WER, качества диаризации, временных меток, RTF и памяти. Исходный текст сохраняется отдельно от обработки LLM.
