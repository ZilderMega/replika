# Ограничения решения

## Поддерживаемые условия

Android 8+, ARM64/x86_64; локальные аудио и аудиодорожка видео; основной ASR русскоязычный. Пунктуация, LLM, шумоподавление, VAD, Whisper и разделение двух голосов работают без сервера. CPU — основной режим. Импорт до 1 ГБ; часовые файлы обрабатываются окнами, а не целиком в float-массиве.

## Известные ограничения

- Обновление v4 проверено на эмуляторе и тех же коротких AMI-фрагментах. Нового полного прогона 82 минут и физического Samsung-замера нет. Кэш ускоряет повторное сопоставление после подготовки признаков; старым записям сначала нужен полный проход голосов. Два блока CPU требуют больше памяти и выключены по умолчанию.
- Уточнение смены голоса использует отдельный WeSpeaker на выбранных 30 с; его качество на произвольных русских интервью не установлено. Привязка сохраняет реальные времена слов ASR и отклоняет несовпадающий вручную изменённый текст. Подтверждённые образцы дают предложения для проверки, а не автоматически устанавливают личность.

- Проверка на двух коротких размеченных AMI-фрагментах обнаружила существенные ошибки говорящих. `speaker_review_N` означает временный локальный голос, требующий проверки; одинаковый человек в разных блоках может получить разные временные метки. Если нативная модель уже объединила двух людей, глобальное сопоставление не восстановит пропущенную смену. Есть ручное разделение реплики по выбранному времени и курсору с сохранением исходника. Результаты: `ANNOTATED_SPEAKER_VALIDATION.md`.

- Профили голосов используют несколько образцов и защиту от неоднозначного назначения; похожие голоса и ошибки исходной сегментации всё ещё требуют проверки. Пороги не откалиброваны на интервью организаторов. Доступны пересчёт участников без повторного ASR и ручное массовое исправление ID. Подробнее — `SPEAKER_CONTINUITY.md`.

- Основная модель ASR русскоязычная и может искажать английскую речь. Для выбранного участка доступен многоязычный Whisper без перевода. Словарь подстановки названий удалён; качество нужно проверять по исходному аудио и независимому текстовому эталону.
- Qwen — настоящий локальный генеративный режим, выбранный отдельно. Для демонстрации обязательного требования LLM нужно показать его запуск. Быстрый RUPunct не выдаётся за генеративную LLM.
- Времена реплик приблизительны, получены из ASR и пересечения интервалов участников. Whisper для фрагмента сохраняет границы выбора и не заявляет точных времён каждого слова.
- Короткие ответы распознаются без жёсткого ограничения диаризацией, однако участник короткого ответа может остаться неизвестным. VAD опционален: порог 0,25, минимальная речь 50 мс, контекст по секунде; при отсутствии детекций используется полный ASR. Это снижает риск потери речи, но не доказывает отсутствие всех пропусков.
- GTCRN может ухудшать отдельные фонемы и чистую речь; очистка шума выключена по умолчанию. Длительность сохраняется дополнением входа для STFT и извлечением исходного диапазона, без сжатия пауз.
- Conv-TasNet — экспериментальный режим двух голосов на участке до 6 с. Модель обучена на английских смесях; качество на русских интервью систематически не измерено. Потоки не являются установленными личностями: `speaker_review_1/2` нужно проверить и связать с правильными ID. Пустой результат одного из голосов не применяется.
- Автоматическое устойчивое восстановление произвольного числа одновременных голосов на всей записи не заявлено. Основной конвейер помечает неоднозначность, а отдельный выбранный фрагмент можно повторно обработать.
- NNAPI — запрошенный provider, а не доказательство использования NPU. Драйвер может выполнять часть графа на CPU. Эмулятор не доказывает ускорение на физическом Samsung. Больше потоков не всегда быстрее.
- Пауза диаризации ожидает текущий нативный блок; после убийства процесса продолжение запускается пользователем. Android ограничивает длительность foreground service.
- Исходники импорта и контрольные точки остаются в приватном хранилище; автоматическая очистка истории пока не реализована. Установка большого APK и обновление моделей требуют дополнительного места.

## Что не входит в текущую версию

Потоковая расшифровка во время записи; гарантированное разделение трёх и более голосов; распознавание личности по общей базе; сертифицированные WER/DER на закрытых записях организаторов; измеренная устойчивость ко всем акцентам и тембрам; гарантированное GPU/NPU-ускорение; подписанный ключом команды production release.

## Риски демонстрации

Перед защитой установить APK и дождаться подготовки моделей, освободить место, выбрать реальные доступные файлы и проверить экспорт. Дополнительные режимы показывать на выбранных коротких фрагментах. Пользовательские правки не выдавать за исходный ASR. Для требования локальной LLM включить Qwen; показать, что сеть приложению не разрешена.

## Дальнейшее развитие

Проверочный размеченный корпус из разных голосов/шумов/перебиваний, автоматическое сравнение моделей по WER/DER/RTF, более сильная билингвальная модель, подтверждённый аппаратный backend на целевом телефоне, локальная сводка решений со ссылками на реплики, SRT/VTT и пользовательский словарь терминов.
