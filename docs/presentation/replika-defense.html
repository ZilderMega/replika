Реплика связывает текст с аудио, показывает участников и позволяет проверить спорный фрагмент.

Задача из материалов Nuclear IT Hack: локальное Android-приложение для структурированной расшифровки разговоров. Не обещать безошибочную стенограмму.

РЕПЛИКА04

Всё остаётся
на устройстве

Без сервера
Без учётной записи
Без загрузки моделей в приложении

Модели включены в APK. Разрешения INTERNET нет. Аудио, история и контрольные точки хранятся локально.

Источники: app/src/main/AndroidManifest.xml, docs/ARCHITECTURE.md, docs/MODELS.md. Первоначальная сборка разработчика требует загрузки зависимостей. Установка и подготовка моделей требуют свободного места.

Pyannote 3 + CAMPPlus

Блоки до 120 с, сопоставление профилей

Быстрый режим по умолчанию

Генеративная LLM

Источники: docs/MODELS.md, scripts/setup-engine.ps1, docs/model-manifest.json. RUPunct не является генеративной LLM. Для демонстрации требования локальной LLM отдельно включить Qwen. TextGuard отклоняет изменение слов и чисел.
