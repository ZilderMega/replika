# Презентация для защиты

13 слайдов в стиле приложения: фон `#F5F0E8`, текст `#252321`, акцент `#9B3F2E`. Крупные заголовки с засечками повторяют характер интерфейса, HTML использует встроенный Manrope из приложения.

- [Анимированная версия для выступления](replika-defense.html): скачать и открыть локально. F — полный экран, N — заметки, стрелки / пробел — навигация. Без внешних зависимостей и сетевых запросов.
- [Редактируемый PowerPoint](replika-defense-ready.pptx): переходы Fade и заметки докладчика. Georgia и Arial доступны в стандартной Windows; на других системах возможна замена шрифтов.
- [Статический PDF](replika-defense.pdf): визуальная копия слайдов, без анимаций.
- [Содержание и заметки](deck.json): общий источник текста.

Все числа снабжены условиями и источниками в заметках. Исторический Samsung и длинное интервью v1 не выдаются за новый полный release-прогон. Свежая пользовательская видеозапись остаётся отдельным материалом.

HTML пересобирается командой `python scripts/build-presentation-html.py`. Раскладка редактируемых слайдов задана в `scripts/build-presentation.mjs`, функция `author(presentation, root)` предназначена для Artifact Session / @oai/artifact-tool. Для локального PPTX после экспорта можно добавить стандартные переходы: `python scripts/add-presentation-transitions.py input.pptx output.pptx`. Файлы финальной презентации включены в репозиторий, устанавливать инструменты для их просмотра не нужно.
