# Сопоставление с заданием Nuclear IT Hack

Источник: предоставленная презентация «Нейро-стенографист», 23 слайда, ноябрь 2026. Обязательные требования — слайды 8–15, проверка — 16, дополнительные уровни — 18–19, материалы — 20–21, веса — 22.

## Как оценивать баллы

Максимумы: текст — 40, диаризация — 25, времена — 10, скорость — 10, работоспособность/UX — 10, защита — 5. Итого 100. Дополнительные функции не имеют собственных фиксированных надбавок. В документе нет формулы перевода WER, DER или RTF в баллы.

Фактическую оценку жюри вычислить нельзя: нет трёх проверочных записей с эталонами и порогов начисления баллов. 85 из 100 баллов требуют измерений качества/времени; наличие дополнительных кнопок их не заменяет. Уровень реализации — базовая и средняя функциональность плюс ограниченные и экспериментальные возможности Ultra Pro Max. Это не утверждение «85/100» и не обещание места на конкурсе.

## Обязательная часть

- Android APK: Kotlin/Compose, ARM64 и x86_64. Все модели входят в APK.
- Локальная LLM: Qwen2.5 0.5B через llama.cpp; реальный запуск проверяется Android-тестом. Для защиты включить режим Qwen. Быстрый RUPunct — отдельный классификатор, не подмена этого требования.
- Импорт: SAF, аудио или аудиодорожка видео; также запись микрофона.
- Распознавание: русский Zipformer с токенами и временами; без серверов.
- Автоматические говорящие: Pyannote + CAMPPlus; неоднозначность остаётся `speaker_unknown`.
- Времена реплик: исходная шкала, построение из ASR и интервалов участников.
- Просмотр: промежуточный/готовый текст, поиск, версии, переход к аудио.
- Экспорт: исходный JSON с точным контрактом; отдельно версия с правками.

## Средний уровень, слайд 18

1. Предварительная обработка: mono, 16 кГц, ресемплинг с low-pass; опциональный GTCRN.
2. Фильтрация пауз/неречевых фрагментов: опциональный Silero VAD с расширением речи контекстом и сохранением времён. Отсутствие детекций не используется как доказательство тишины.
3. Смена участников: голосовые прототипы сопоставляются между блоками и сохраняются. Ошибки кластеризации на реальных интервью ещё нужно измерить.
4. Пунктуация: RUPunct по умолчанию, Qwen отдельно; TextGuard защищает слова.
5. Прогресс: обработанное время аудио/количество фрагментов, общее время, время этапа и текущего участка, ETA текущего этапа.
6. Проигрывание: переход к началу выбранной реплики, пауза/продолжение.

## Ultra Pro Max, слайд 19

1. **Фоновый шум:** GTCRN включается отдельно. Сохранность длины проверяется; улучшение точности на всех шумах не заявляется. Нужен размеченный шумовой корпус.
2. **Короткие реплики и перебивания:** ASR не ограничивается жёсткой маской диаризации, есть контекст и адаптивные окна. Короткое «я» проверяется отдельно. Участник короткого ответа всё ещё может быть неизвестен.
3. **Одновременная речь:** Conv-TasNet локально разделяет выбранный участок до 6 с на два потока, затем выполняется ASR и ручная проверка обоих ID/текстов. Это ограниченная экспериментальная возможность; автоматическая точная обработка всех наложений на всей записи не заявляется.
4. **Разные тембры/манера речи:** используются акустические эмбеддинги и автоматическая кластеризация. Систематическая устойчивость к тембрам и акцентам не подтверждена независимым набором. Этот пункт нельзя считать полностью закрытым одним тестом двух голосов.
5. **Оперативная память:** PCM на диске, ограниченные окна, последовательная загрузка тяжёлых моделей, освобождение ресурсов и контрольные точки. Запуск на всех телефонах с 4 ГБ не гарантирован.
6. **Аппаратные возможности:** явные CPU-потоки и измерение разных конфигураций, экспериментальный NNAPI. Использование NPU/GPU не выдаётся за доказанный факт; данные эмулятора не переносятся на телефон.
7. **Редактор/повторная обработка:** текст, участник, времена, отдельный слой правок, seek к фрагменту, очистка/Whisper/разделение по выбору. Исходный JSON остаётся отдельным.

## Исправление путаницы участников

Используется банк чистых голосовых образцов вместо единственного замороженного прототипа. Два последовательных локальных кластера допускается связать с одним ID, одновременные — нет; неоднозначные совпадения остаются неизвестными. Можно задать монолог или верхнюю границу участников, пересчитать только диаризацию, вручную применить исправленный ID ко всем репликам участника. Подробности и пределы — `SPEAKER_CONTINUITY.md`. Это усиление функциональности, а не доказательство заданного DER на русских интервью.

## Иноязычная речь

Русская модель ASR может неверно распознавать английские слова. Пунктуация не исправляет лексику: TextGuard запрещает менять слова. Для уточнения используется повторное распознавание выбранного диапазона через Whisper (`transcribe`, без перевода). Словарь подстановки отдельных названий и отдельный переключатель удалены по уточнению пользователя. Качество иноязычной речи проверяется по исходным аудиозаписям и независимому текстовому эталону.

## Полезные функции вне списка

Уже добавлены поиск по словам/участнику, фильтр реплик с неопределённым участником, отдельные экспорты и защищённый исходный текст. Сильный сценарий защиты — показать, где модель ошиблась, прослушать это место, уточнить только его и доказать сохранность исходника.

Дальнейшие идеи: локальная сводка решений со ссылками на реплики; пользовательский словарь имён и терминов; SRT/VTT. Это предложения, а не заявленные готовые функции.
