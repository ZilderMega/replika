# Архитектура решения

## Контекст

Реплика — локальный стенографист для Android. Kotlin/Jetpack Compose реализуют интерфейс и жизненный цикл; JNI запускает модели на устройстве. В манифесте нет INTERNET. Нет облачных API и удалённого инференса.

## Компоненты

В обновлении v4 добавлены `VoiceBlock`/`VoiceReconciliation` (сохранение признаков и позднее уточнение неподтверждённых назначений), `SpeakerTurnRefinement` (локальный WeSpeaker без повторного ASR), `SpeakerAssistance` (подтверждённые образцы и предложения ID), `DiarizerPool` (до двух независимых моделей с делением бюджета CPU). `SpeakerSuggestionsDialog` применяет только явно выбранные ID; результат привязан к номеру запроса, чтобы не открывать старые/пустые предложения до завершения поиска. Экспорт исходника сохраняется отдельно.

- MainActivity: импорт, история, проигрывание с переходом к реплике, поиск, выбор версии текста, экспорт и редактор.
- EngineViewModel: состояние интерфейса и запуск foreground service.
- ProcessingService: фоновая задача, уведомление, wake lock, таймеры, контрольные точки и отдельная обработка выбранного фрагмента.
- AudioDecoder: MediaExtractor/MediaCodec, выбор аудиодорожки, mono PCM16 16 кГц. Повторная обработка использует seek и декодирует только выбранный диапазон.
- AudioPreparation: опциональный GTCRN для шума и Silero VAD для пауз. PCM остаётся на исходной временной шкале.
- Small Zipformer RU: ASR с токенами и временными метками, ограниченные окна и адаптивный повтор на меньшем окне при ошибке.
- Pyannote 3 + CAMPPlus: диаризация, автоматические кластеры и сопоставление участников между блоками.
- VoiceMatcher: несколько чистых образцов на голос, обновляемый профиль, проверка конкурирующих совпадений и явные неизвестные интервалы. Подробности — `SPEAKER_CONTINUITY.md`.
- Alignment: слова, активные интервалы участников, реплики до 20 с, осторожное поведение при пересечении голосов.
- RUPunct_small INT8: быстрая пунктуация; Qwen2.5 0.5B Q4_K_M через llama.cpp — дополнительный режим локальной LLM.
- FragmentProcessor: повторное ASR, опциональная очистка шума, Whisper tiny multilingual с задачей `transcribe` и экспериментальное разделение двух голосов Conv-TasNet.
- TranscriptTools/TranscriptEditor: редактируемая версия без перезаписи исходного текста; автоматических лексических подстановок нет.

## Основные решения

Текст показывается до диаризации и пунктуации. Тяжёлые этапы основного конвейера загружаются последовательно, каждая модель — один раз за проход. Длинное аудио и контрольные точки хранятся на диске, float-массивы ограничены текущим блоком. Количество CPU-потоков задаётся явно; NNAPI доступен как экспериментальный запрашиваемый provider, без обещания использования NPU.

Полноценное разделение голосов не включено автоматически для всех часов записи. Оно запускается на выбранном участке до 6 с; обе гипотезы необходимо прослушать и проверить. Это ограничивает память, задержку и риск незаметного ухудшения основного результата.

## Зависимости и модели

Версии и URL моделей закреплены в `scripts/setup-engine.ps1`, SHA-256 — в `docs/model-manifest.json`. Применяется один ONNX Runtime из sherpa-onnx AAR, без дополнительной копии runtime. Все модели входят в APK и подготавливаются в приватном хранилище. Лицензии и attribution находятся в `app/src/main/assets/licenses`.

Whisper предназначен для повторного распознавания фрагментов со смешанной речью; его режим не переводит текст (`task=transcribe`). Времена выбранного диапазона сохраняются; точность словесного выравнивания Whisper здесь не заявлена.

## Безопасность и приватность

Приватное хранилище Android, резервное копирование отключено, службы не экспортируются. Запись микрофона требует разрешения и foreground notification. Исходный импортированный файл остаётся локально для продолжения и повторной обработки. Аудио не отправляется внешним сервисам. Публиковать пользовательские записи вместе с материалами сдачи не требуется.
