# Проверка на физическом Samsung

Устройство: SM-S936B, Android API 37. Все аудиовычисления выполнены на телефоне.

## Скорость

Публичная запись 35,4 с, уже находящаяся в приложении. По три полных прохода на конфигурацию; медиана. Включены декодирование, загрузка моделей этапов, ASR, диаризация и быстрая пунктуация. Начальная установка/подготовка моделей не включена.

- cpu, 2 потока: 10.090 с; прогоны [9354, 10090, 13159]; максимум выборок PSS 298.9 МиБ.
- cpu, 4 потока: 9.088 с; прогоны [10814, 8768, 9088]; максимум выборок PSS 306.2 МиБ.
- cpu, 6 потока: 9.005 с; прогоны [9005, 8816, 10552]; максимум выборок PSS 300.8 МиБ.
- nnapi, 4 потока: 10.331 с; прогоны [9086, 11142, 10331]; максимум выборок PSS 285.7 МиБ.

Слова ASR во всех проходах совпали: True. Выбран CPU, 4 потока. Разницу меньше 5% на этом коротком тесте не используем как основание менять четыре потока. Число потоков доступно пользователю.

Порядок фиксирован, фоновые приложения и температура окружения не контролировались. NNAPI не считается доказательством NPU. Замеры быстрого режима не включают генеративную Qwen.

## Иноязычная речь

Два реальных публичных английских монолога с опубликованными текстами из trans.txt, включённого в зафиксированный комплект sherpa. Длительности/хэши/источники: artifacts/test-results/corpus/manifest.json. Это небольшая диагностическая выборка, а не общая оценка интервью.

- english.wav, russian: WER 100.00% (18 ошибок на 18 слов), 2303 мс.
- english.wav, multilingual: WER 0.00% (0 ошибок на 18 слов), 1317 мс.
- english-second.wav, russian: WER 100.00% (48 ошибок на 48 слов), 2520 мс.
- english-second.wav, multilingual: WER 8.33% (4 ошибок на 48 слов), 2152 мс.

Русский ASR не предназначен для произвольной английской речи. Для выбранного фрагмента используется многоязычный Whisper с transcribe, без перевода. Автоматический словарь отдельных названий удалён. Основной проход всего файла остаётся русскоязычным; автоматическая точная транскрибация любого смешанного интервью не заявляется.

Второй английский пример содержит ошибки и варианты написания (например, слитное/раздельное слово); исходный эталон не изменяли ради улучшения WER. WER игнорирует регистр/пунктуацию, но не переводит и не транслитерирует слова.

## Память, температура и заряд

До прогона: {'battery_percent': 84, 'battery_temperature_c': 34.1, 'plugged': 0, 'thermal_status': 0, 'process_pss_kib': 91864}. После: {'battery_percent': 83, 'battery_temperature_c': 37.1, 'plugged': 0, 'thermal_status': 0, 'process_pss_kib': 146906}.

PSS измеряется раз в 500 мс и может пропустить пик. Температура относится к батарее, не к CPU. Разница процентов заряда относится ко всему устройству; это не измерение энергии приложения.

## Приватность и воспроизводимость

Для ускорения Wi-Fi-обновления использован debug APK только с кодом и манифестом моделей: уже установленные модели сверены по манифесту и SHA-256. Обычная сборка/комплект сдачи содержит все модели. Такой облегчённый APK нельзя использовать для чистой установки или восстановления удалённых моделей.

После измерений на телефон возвращён полный автономный APK; отдельно проверено восстановление повреждённой модели из его ресурсов. Реальный длинный прогон и проверка продолжения описаны в LONG_RECORDING_VALIDATION.md; независимая человеческая разметка AMI — в ANNOTATED_SPEAKER_VALIDATION.md.

Личные записи, их пути, выдержки и стенограммы не входят в публичные артефакты. Для них используется игнорируемая .private-validation. Без проверенной ручной разметки личной записи не рассчитывается WER/DER. Синтетические шум/наложение явно отделены от реального диалога.

Исходные измерения: artifacts/test-results/samsung/physical-validation.json; вычисления: summary.json; повторный расчёт: python scripts/summarize-phone-validation.py.
