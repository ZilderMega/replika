# Комплект сдачи «Реплика» 0.6.0

Android-приложение для локального преобразования аудио и видео в стенограмму с участниками и временными метками. Дата подготовки комплекта: 8 ноября 2026. Основной язык ASR — русский. Все этапы инференса выполняются на устройстве.

## Что передать экспертам

1. **Подписанный release APK:** `artifacts/replika-0.6.0-release.apk` в ZIP комплекта либо отдельным файлом. Полные модели входят в APK. Это не debug и не облегчённое обновление с отсутствующими весами.
2. **Исходники:** этот репозиторий либо `replika-0.6.0-source.zip`. Android-модуль находится в `app/`, вход по структуре шаблона — [src/mobile](../src/mobile/README.md). Инструкции получения весов и сборки включены.
3. **Установка и использование:** [INSTALLATION.md](INSTALLATION.md), [USER_GUIDE.md](USER_GUIDE.md).
4. **Архитектура и модели:** [ARCHITECTURE.md](ARCHITECTURE.md), [MODELS.md](MODELS.md), [контракт JSON](PROTOCOL.md), [контрольные суммы моделей](model-manifest.json).
5. **Ограничения:** [LIMITATIONS.md](LIMITATIONS.md). Ошибки диаризации и ограничения русской модели названы явно.
6. **Собственные тесты:** [проверка текущего комплекта](SUBMISSION_VALIDATION.md), [история проверок](TEST_RESULTS.md), [Samsung](PHONE_VALIDATION.md), [голоса v4](VOICE_V4.md). Исходные логи включены в `artifacts/test-results`.
7. **Видеодемонстрация:** существующие публичные примеры и пояснения находятся в [artifacts/demo](../artifacts/demo/README.md). Автор отдельно записывает свежую демонстрацию нового release по [сценарию](USER_GUIDE.md#сценарий-самостоятельной-видеозаписи). До её добавления этот пункт не следует считать закрытым для новой сборки.
8. **Презентация:** [PowerPoint](presentation/replika-defense-ready.pptx), [PDF](presentation/replika-defense.pdf), [анимированная HTML-версия](presentation/replika-defense.html). Для HTML скачайте файл и откройте в браузере. GitHub показывает исходный текст HTML, а не запускает презентацию.

Полный локальный комплект: `artifacts/replika-0.6.0-submission.zip`. SHA-256 каждого вложения находится в `SHA256SUMS.json`. Отдельный `release-manifest.json` фиксирует APK, подпись и проверки. Архив исходников исключает модели и сторонние бинарные зависимости, но содержит скрипт их получения с проверкой хэшей.

После сборки release комплект воспроизводится командой `python scripts/package-release.py`. Скрипт проверяет модели и подпись по логу сборки, создаёт манифест, исходный и полный ZIP. Старый `package-submission.py` сохранён для исторического debug-комплекта и для новой сдачи не используется.

## Как показать презентацию

Для выступления откройте HTML-файл: все изображения и шрифт встроены, сеть не требуется. Стрелки, Page Up / Page Down и пробел переключают слайды; F включает полный экран, N показывает заметки докладчика. На сенсорном экране доступен горизонтальный свайп. В настройках уменьшения движения браузер отключает анимации.

PowerPoint содержит 13 редактируемых слайдов, встроенные экраны приложения, заметки и стандартные переходы Fade. Веб-версия дополнительно использует последовательное появление текста, движение экранов и плавную смену композиции. PDF — статическая копия для просмотра, без анимаций и редактирования текста.

## Соответствие шаблону

Основа структуры — [grigorevmp/hacathon_template](https://github.com/grigorevmp/hacathon_template): `docs`, `config`, `src`, `artifacts`. Стандартный Gradle-модуль остаётся в `app`, его код не дублируется в `src/mobile`. Карта требований: [TASK_REQUIREMENTS.md](TASK_REQUIREMENTS.md).

## Доступ и ветки

Публичность `https://github.com/ZilderMega/replika` подтверждена через GitHub API при подготовке комплекта. Авторизация экспертам для публичного исходного кода не требуется. Новые материалы подготовлены в ветке `codex/submission-release-materials`; `main` не изменяется этой работой. Для сдачи передавайте ссылку именно на ветку с комплектом, а не на прежнее содержимое `main`.

Личные аудио, приватные стенограммы, SDK-пути компьютера, кэши и ключ подписи в комплект не включаются. Исторические демонстрации и измерения подписаны отдельно от актуальной release-проверки.
