# Установка «Реплики» 0.6.0

## Готовое приложение

Скачайте **replika-0.6.0-release.apk** со [страницы комплекта сдачи](https://github.com/ZilderMega/replika/releases/tag/v0.6.0-submission). Это автономный подписанный APK, включающий модели. Debug APK и облегчённые обновления разработчика для сдачи не используются.

Требования: Android 8.0 (API 26) или новее, ARM64 либо x86_64. Рекомендуется минимум 4 ГБ свободного места для установки и подготовки моделей, дополнительно требуется место под записи и временный PCM. Производительность на всех устройствах с 4 ГБ RAM не гарантируется. Интернет при работе приложения не нужен.

1. Сохраните APK на телефон и откройте его в файловом менеджере.
2. Если Android запросит, разрешите этому файловому менеджеру установку неизвестных приложений. После установки разрешение можно отключить.
3. Откройте «Реплику». Дождитесь подготовки и проверки встроенных моделей. Не удаляйте данные приложения во время подготовки. При прерывании откройте приложение и нажмите «Повторить подготовку».
4. Разрешение на микрофон нужно только для записи. Разрешение на уведомления позволяет видеть состояние фоновой обработки.
5. Добавьте аудио или видео и выполните короткий пробный проход по [инструкции](USER_GUIDE.md).

Release подписан отдельным постоянным локальным ключом проекта. Он отличается от Android debug-ключа: поверх ранее установленной debug-версии APK не установится. Сначала экспортируйте нужные результаты, сохраните исходные аудиофайлы вне приложения, затем удалите debug-версию и установите release. **Удаление приложения удаляет его приватную историю и контрольные точки.** Не удаляйте старую версию до сохранения нужных данных. Последующие release-обновления тем же ключом устанавливаются поверх неё.

Для установки с компьютера: `adb install -r artifacts/replika-0.6.0-release.apk`. Ошибка `INSTALL_FAILED_UPDATE_INCOMPATIBLE` означает несовместимые подписи. Не выполняйте автоматическое удаление приложения ради обхода ошибки.

## Проверка целостности

На странице релиза опубликован `release-manifest.json` с SHA-256 APK и отпечатком сертификата. В PowerShell: `Get-FileHash ./replika-0.6.0-release.apk -Algorithm SHA256`. Значение должно совпадать с манифестом.

## Сборка из исходников

Исходный код находится в `app/`, конфигурация — в `config/`, вход по структуре шаблона — в `src/mobile/README.md`. Установите Git, PowerShell 7, JDK 17+, Android SDK 35, NDK 27.1.12297006 и CMake 3.22.1. Укажите SDK в локальном `local.properties`. На компьютере для первоначального получения зависимостей нужен интернет.

```powershell
git clone --branch codex/submission-release-materials https://github.com/ZilderMega/replika.git
cd replika
./scripts/setup-engine.ps1
./scripts/build-release.ps1
```

`build-release.ps1` создаёт ключ только при первом запуске и хранит его с локальной конфигурацией вне репозитория: `%USERPROFILE%/.android/replika-release`. Сохраните эту папку в защищённой резервной копии для последующих обновлений. Другой разработчик создаст собственную подпись, поэтому его APK не обновит установленный пакет с нашей подписью. Не публикуйте ключ или `signing.json`.

Для существующего ключа задайте `-SigningDirectory <папка>`. Скрипт запускает сборку release, JVM-тесты release и Lint release. Для разработки доступна команда `./gradlew.bat :app:assembleDebug :app:testDebugUnitTest :app:lintDebug`.

## Если возникла проблема

Не хватает места: освободите хранилище, учитывая временную копию моделей при обновлении. APK не открывается: проверьте завершение загрузки, SHA-256, версию Android и ABI. Файл не читается: повторно выберите его системным диалогом и убедитесь, что он доступен локально. Подготовка моделей прервана: используйте повторную подготовку. Подробности эксплуатации — в [руководстве](USER_GUIDE.md).
