- Отдельная чистая установка подписанного release на тестовый AVD успешна. Холодный запуск `am start -W`: `Status: ok`. После каждого скрытия проверены открытый редактор и неизменный введённый ID. Затем проверены ручное разделение реплики, сохранение правок и неизменность исходной стенограммы. Этот UI-тест выполнялся на debug-сборке того же кода. После него выполнена отдельная release-сборка с JVM-тестами и Lint. Это не полный Android-прогон всех возможностей на подписанном release и не повтор Samsung-бенчмарков.

## Что обнаружили при проверке

Первый эмулятор имел недостаточно свободного места для большого APK; его данные не удаляли, создали отдельный тестовый AVD с 10 ГБ разделом данных. Старый APK не содержал текущего класса `BundledModels`, поэтому запуск нового теста до установки актуальной сборки не был валидной проверкой исправления.

В тестовом сценарии ожидание первоначальной подготовки моделей уточнено до состояния `modelsReady && !busy`. Затем тест обнаружил реальную проблему: кнопка, обращавшаяся к контроллеру основного окна, не скрывала клавиатуру диалога. Контроллер и фокус перенесены внутрь содержимого `AlertDialog`, после чего целевой сценарий прошёл. Логи неуспешных этапов сохранены отдельно, не выдаются за успешные прогоны.

## Презентация и комплект

13 слайдов, все просмотрены после рендера. PowerPoint проверен структурным валидатором, проверкой геометрии/шрифтов и повторным импортом Artifact Tool. Содержит редактируемые тексты, встроенные экраны, заметки и стандартные переходы Fade. Нативный показ в Microsoft PowerPoint не проверялся.

HTML проверен в headless Chrome: навигация по всем 13 слайдам, загрузка встроенных изображений, отсутствие ошибок JavaScript. PDF содержит 13 статических страниц 16:9. Целостность ZIP и SHA-256 моделей/APK проверяет `scripts/package-release.py`.

## Какие выводы делать нельзя

Эти проверки не дают нового WER/DER русской речи, гарантий качества на закрытом наборе жюри или ускорения на NPU. Данные скорости Samsung и длинного интервью относятся к историческим проходам, описанным отдельно. Полного нового 82-минутного прогона v4 и проверки исправления клавиатуры на физическом Samsung нет. Свежую видеодемонстрацию release записывает автор.
