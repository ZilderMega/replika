# Демонстрация Реплики 0.6

Эти видео сняты до объединения веток истории/плеера и иконки. Сценарии редактора и обработки остаются показательными; объединённые плеер и история проверены отдельно: `artifacts/test-results/merged-ui-after-fixes.txt` и `history-player-proof.json`.

Обновление сопоставления голосов: `replika-0.6-voice-update.mp4` — непрерывная запись текущей сборки во время полного регрессионного прогона (около 148 с, включает ожидание тестов). `replika-0.6-voice-update-short.mp4` — непрерывный отрезок 90–124 с без внутренних монтажных склеек: обработка, просмотр и ручная правка через редактор. В нём показываются таймеры и обновлённый интерфейс пересчёта участников. Ручной текст Java/YouTube явно отделён от результата ASR.

Следующие записи сделаны до обновления сопоставления голосов, во время подготовки исходной версии 0.6:

`replika-0.6-demo.mp4` — запись реального Android-эмулятора, около 55 секунд. Без подмены инференса подготовленным текстом.

`replika-0.6-demo-short.mp4` — непрерывный отрезок 23–45 с того же видео без смены кадров внутри; запуск/ожидание убраны только с краёв. Подходит для короткого показа интерфейса и редактора.

Сценарий: запуск приложения и подготовка, настоящий ASR публичного русского `0.wav` из комплекта sherpa, определение участников, быстрая пунктуация, просмотр и открытие редактора. Автоматический исходный текст — «я тебя люблю». Затем тест явно вводит текст «Ручная правка: Java и YouTube.» в отдельную версию и проверяет, что исходный JSON не изменился.

Ручная правка в этом видео не выдаётся за результат распознавания английских слов. Whisper и разделение голосов проверены отдельными Android-сценариями; выводы находятся в `artifacts/test-results`. Видео не содержит пользовательских записей.

`editor-screen.png` показывает реальный редактор. В начале видео есть запуск/подготовка; для короткой защиты можно использовать фрагмент после появления главного экрана.

Запись создана через `adb shell screenrecord`; исходный звук в MP4 не записывается. Для проверки обязательной генеративной LLM отдельно показать обработку с включённой Qwen: быстрый режим в этом видео использует RUPunct.
