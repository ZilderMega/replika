# Реальные проверки и измерения

См. `docs/TEST_RESULTS.md` для методики, окружения и ограничений. CSV содержит только фактически полученные времена. Пустые WER/DER означают, что независимого эталона не было; это не нулевые ошибки.

`editor-proof.json` содержит исходный результат реального ASR и отдельную ручную редакцию. Это проверка сохранности данных, не эталон распознавания.

`voice-continuity.json` — реальные интервалы и ID после сохранения/загрузки банка голосов между блоками; `voice-recalculation.json` — сохранение ASR при пересчёте участников. Неизвестные интервалы не скрыты и не считаются верными ответами. `build.json` содержит SHA-256 APK и число пройденных проверок. `device-current.json` сохраняет холодные ранние проходы, `full-speed.json` — более поздние прогретые.

Данные предназначены для воспроизведения и анализа. Ни одна тестовая стенограмма не встроена в приложение вместо работы модели.
